# Comiquería Central - Pre-Entrega 5

Proyecto realizado para la Pre-Entrega 5 de JavaScript en Coderhouse.

En esta entrega transformé el catálogo en objetos creados con la clase
`Producto`. Cada producto tiene `id`, `nombre`, `precio`,
`categoria` y `stock`.

La clase tiene los métodos `vender()`, `reponer()` y
`obtenerPrecioConIva()`. El carrito y el simulador usan esos objetos para
calcular los precios y actualizar el stock.
